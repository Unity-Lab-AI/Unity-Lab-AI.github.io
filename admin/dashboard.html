Bot enrolled. The token below is shown once — but it's already baked into the proxy.js you'll download below, so you don't need to paste it anywhere by hand. The Copy button is just so you can stash it in a password manager if you want a backup.

        

        

        
Step 1 — Download your proxy.js

        
This file is unique to this bot — your token + bot ID are baked into it, no manual paste required. Filename will be unity-proxy-<bot-id>.js.

        Download proxy.js

        
Step 2 — Move it into your .claude/proxy/ folder

        
Move the downloaded file into the proxy/ subfolder of whichever .claude/ directory you launch Claude Code from. Two common locations:

        
    
          
  • Project-local: <your-project>/.claude/proxy/ — e.g. C:/Users/you/Desktop/myproject/.claude/proxy/
    • 
          
  • User-global: ~/.claude/proxy/ — e.g. C:/Users/you/.claude/proxy/ on Windows, /Users/you/.claude/proxy/ on macOS
    • 
        

        
If the proxy/ folder doesn't exist, create it. You can keep the original filename or rename to proxy.js — just remember which one you chose for Step 3.


        
Step 3 — Register it in your settings.local.json

        
The settings file lives next to your .claude/ folder at .claude/settings.local.json.


        
Case A — file doesn't exist yet: create it with EXACTLY this content (replace the path with your actual file path from Step 2):

        
{
  "mcpServers": {
    "unity-admin-portal": {
      "command": "node",
      "args": ["C:/Users/YOU/.claude/proxy/unity-proxy-BOTID.js"]
    }
  }
}

        

        
Case B — file already exists with content: JSON only allows ONE root object per file. Do NOT paste a second { ... } block at the end — that's a parse error. Instead, find the existing "mcpServers": { ... } object and add the unity-admin-portal entry INSIDE it. If there's no "mcpServers" key yet, add it as a new top-level key (not as a separate root object).

        
Example of a CORRECT merged result if you already had a permissions block:

        
{
  "permissions": {
    "allow": ["Bash(node:*)", "Bash(npm:*)"]
  },
  "mcpServers": {
    "unity-admin-portal": {
      "command": "node",
      "args": ["C:/Users/YOU/.claude/proxy/unity-proxy-BOTID.js"]
    }
  }
}

        

        
⚠️ Path tips for Windows: use forward slashes C:/Users/... OR escaped backslashes C:\\Users\\... — single backslashes break JSON. ~ may not expand reliably; absolute paths always work.


        
Step 4 — Restart Claude Code

        
Run start.bat / start.sh. On first run the proxy generates an Ed25519 keypair locally and registers itself — bot will appear online in the sidebar within ~30s. If it doesn't, check Claude Code's MCP server log for path/spawn errors.
