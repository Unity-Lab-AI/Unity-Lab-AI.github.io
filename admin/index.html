Admin Portal

Browser login is disabled. The only way to sign in is via your local .claude/ template.

  1. On your local machine, open the folder where .claude/ is installed.
  2. Run .claude\start.bat (Windows) or .claude/start.sh (macOS/Linux).
  3. The setup wizard will ask which admin you are + your password.
  4. It will then open this page (well, the dashboard) in your browser, already signed in.

Don't have .claude/? Ask the founder to send you the universal template (Signal/in-person — never email).

Dev mode — pick an admin to log in as. Localhost only. The backend rejects this if reached through Cloudflare or any reverse proxy.
