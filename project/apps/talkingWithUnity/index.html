What the lights mean

Checking now. Green means ready. Amber means we need to fix that before Unity can listen.

  • Secure connection (HTTPS or localhost) Checking…

    Secure connection detected.

    Open with https:// or from localhost, then press "Check again."

  • Web Speech Recognition API Checking…

    Speech recognition available.

    Firefox is supported via Vosklet fallback.

  • Speech synthesis voices Checking…

    Speech voices ready.

    Use Chrome, Edge, or Safari with audio enabled, then press "Check again."

  • Microphone access Checking…

    Microphone permission granted.

    Click "Allow" on the microphone prompt, then press "Check again."

How to get every light to glow green

  1. Stay on a secure connection. Load via https:// or localhost.
  2. Use Chrome or Edge. Safari works on macOS.
  3. Give Unity ears. Enable speakers and allow microphone access when prompted.
  4. Re-run the check. Press "Check again" after changes. All green = "Talk to Unity" unlocks.
  5. Unmute on load. Tap anywhere when the lab loads so Unity can hear you.
