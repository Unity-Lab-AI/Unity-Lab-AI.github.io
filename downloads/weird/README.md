# DUNGEON MASTER: THE HUNT — download reference

This folder is **reference-only**. It does NOT serve the playable game.

## To play the game

→ **Apps page:** [DUNGEON MASTER: THE HUNT](../../apps/weird/index.html)

→ **Apps directory:** [/apps](../../apps.html)

## To download the source

→ **Archive:** [weird.zip](../files/weird.zip)

The archive contains the full client (HTML / JS / CSS / assets / docs) ready to extract and run locally. Requires Ollama installed on your machine for the LLM backend; everything else (Kokoro TTS, IndexedDB save) runs in your browser.

## To get the latest source

→ **GitHub:** https://github.com/Unity-Lab-AI/Weird

The repo's `main` branch deploys to GitHub Pages and is also mirrored into `/apps/weird/` on this site.
